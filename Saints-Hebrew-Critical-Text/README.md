# Saints Hebrew Critical Text

- **Canonical Scope:** 39 Old Testament books · 929 chapters · 23,213 verses (Hebrew & Biblical Aramaic)
- **Method:** Reasoned eclecticism over open-licence Tiers 1–3 Masoretic witnesses (Tier 5 NonCommercial / copyrighted editions strictly excluded).
- **Source Studio:** Generated by Saints Critical Text Studio (`01_Law/` through `04_Providence/`).

## File Formats per Chapter
- `*_Critical_Text.md` — Four-section critical edition (Witness Declaration, Continuous Critical Text, Apparatus & Disregarded Noise Log, Verse-by-Verse Rationale).
- `*_Critical_Text.tsv` — Verse-level tabular critical text (`verse`, `critical_text`, `confidence`, `decision_source`, etc.).
- `*_Critical_Text.json` — Full structured collation, apparatus, and witness readings.
